# 📁 Smart Folder Organizer (스마트 업무 폴더 정리 웹앱)

다운로드 폴더나 바탕화면의 뒤섞인 파일들을 **100% 브라우저 로컬 환경**에서 분석하여, 사용자가 설정한 업무 폴더 규칙과 파일명 연관성(공통 단어·날짜 패턴)에 따라 자동으로 분류하고 실제 폴더로 정리해 주는 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **100% 로컬 처리 & 보안 (File System Access API)**
   - 어떤 파일 데이터도 외부 서버로 업로드되지 않으며, 브라우저 메모리 내에서 안전하고 빠르게 처리됩니다.
2. **사용자 맞춤형 업무 폴더 관리 (CRUD + 영구 저장)**
   - 원하는 업무 폴더명(예: `기획_업무문서`, `회계_영수증_재무`, `2026_신규프로젝트`)을 직접 추가·수정·삭제할 수 있습니다.
   - 각 폴더별 매칭 키워드, 확장자, 라벨 색상을 설정할 수 있으며 `localStorage`에 자동 보관됩니다.
   - 폴더 규칙을 수정하면 열려 있는 파일 목록에 실시간으로 자동 재분류가 적용됩니다.
3. **2단계 하이브리드 분류 엔진**
   - **1단계 (규칙 매칭):** 사용자가 정의한 폴더의 키워드 및 확장자 우선 매칭
   - **2단계 (AI 스마트 클러스터 발견):** 미분류 파일들 중 공통 날짜 패턴(`YYYY-MM`)이나 공통 프로젝트 접두어를 자동 감지하여 원클릭 폴더 생성을 제안
4. **인터랙티브 미리보기 & 안전한 파일 이동**
   - 정리 실행 전 요약 대시보드와 폴더별 이동 결과를 미리 확인하고, 개별 파일을 드롭다운으로 손쉽게 재배치할 수 있습니다.
   - 동일 파일명 충돌 시 자동으로 `_(1)`, `_(2)` 넘버링을 부여하여 덮어쓰기 유실을 방지합니다.
5. **샘플 데이터 데모 모드 탑재**
   - 실제 폴더를 선택하기 전, 18개의 리얼한 샘플 파일로 모든 분류·클러스터링·정리 시뮬레이션을 즉시 체험해 볼 수 있습니다.

## 🚀 시작하기 (Getting Started)

### 필수 환경
- **Node.js** 18+
- **권장 브라우저:** Chrome, Edge, Whale 등 Chromium 계열 최신 브라우저 (File System Access API 지원)

### 설치 및 실행

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

---

## 🛠️ 기술 스택
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Lucide Icons
- **Browser API:** File System Access API (`showDirectoryPicker`), Web Storage API (`localStorage`)
